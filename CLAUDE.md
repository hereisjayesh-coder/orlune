# Orlune

This is a pointer file for Claude Code sessions — the real content lives elsewhere so
it stays usable by any agent, not just Claude Code.

Read, in order:

1. **`AGENTS.MD`** — permanent rules: product identity, forbidden technologies,
   architecture, privacy requirements, build/test commands, coding conventions, Git
   workflow, migration rules, known platform limitations.
2. **`docs/PROJECT_STATE.md`** — dated snapshot: current phase, build/test status,
   known bugs, next recommended task. This changes often; `AGENTS.MD` rarely does.

Do not duplicate their content here — update those two files directly, and keep this
one a pointer only.
